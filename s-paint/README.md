# SPaint

A simple painting app built with Java swing.

## Description

A simple painting app inspired by MSPaint.  
- 'S' to save your current drawing and have it loaded up on the next run.
- 'C' to delete the current drawing.
- 'Z' to undo the last line. 


Uses Java's built in MouseListener, MouseMotionListener & KeyListener to track mouse movements and user inputs; ArrayLists to store the points in each drawn line; a novel (and perhaps suboptimal) method to store previous drawings with a .txt file.

### Installing & Executing program

- Download and compile all of the files
- Run SPaint.java
